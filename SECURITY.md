# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest (`main`) | ✅ |
| older releases  | ❌ |

Only the most recent release receives security fixes. We recommend always
running the latest version.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

To report a vulnerability, email the maintainers at:

**t.blackstone@inspyre.tech**

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept (if applicable).
- Any suggested mitigation or fix you may have.

You can expect an acknowledgement within **72 hours** and a resolution
timeline discussion within **7 days** of your initial report.

We will coordinate a disclosure date with you and credit you in the release
notes unless you prefer to remain anonymous.
